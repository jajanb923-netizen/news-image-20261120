Sum up 20 November's world news in one image: a one-page newspaper front page for Friday 20 November 2026 — the fresh Russian missile attack on Kyiv, GTA VI's record $2.36 billion launch day, Asian markets plunging on AI-bubble fears, a Houthi missile damaging the Saudi wealth-fund tower in Riyadh, and the UK-EU youth mobility deal, with a ticker of the day's other stories. The image is drawn by `draw.py` (Pillow) from the day's real reporting, and `main.py` copies it to `/output/entry.png`.

## Run it

```sh
python3 main.py
```

Local run (writes to `./out/entry.png` instead of `/output/entry.png`):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
